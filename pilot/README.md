# Pilot study (September 2026)

First feasibility check that motivated this repository: 2-task Permuted-MNIST and
Split-FashionMNIST (domain-IL), MLP 784-200-200, plain SGD, 5 seeds each, trapezoidal rule.
`pilot_summary.txt` holds the aggregated numbers. The pilot code is kept verbatim for
provenance; the maintained implementation is the `flgr` package.
